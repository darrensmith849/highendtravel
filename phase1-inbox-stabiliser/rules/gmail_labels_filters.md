# Gmail Labels & Filters — Phase 1 Inbox Stabiliser

## Labels to Create

Create these labels in Gmail (Settings → Labels → Create new label):

| Label | Purpose |
|---|---|
| `TRIAGE/0-Inbox` | New inbound threads flagged by the system |
| `TRIAGE/1-Needs Reply` | Threads that need a human reply |
| `TRIAGE/2-Waiting Client` | Reply sent, awaiting client response |
| `TRIAGE/3-Waiting Partner` | Waiting on a partner/vendor |
| `TRIAGE/4-Closed` | Resolved threads |
| `TRIAGE/Escalate` | Escalated to senior staff |
| `TRIAGE/Processed` | Thread has been ingested into the tracker (system-managed) |
| `TRIAGE/Auto` | Draft was auto-generated by the system |

### Label colours (recommended)
- `0-Inbox` → Red
- `1-Needs Reply` → Orange
- `2-Waiting Client` → Yellow
- `3-Waiting Partner` → Blue
- `4-Closed` → Green
- `Escalate` → Purple
- `Processed` → Grey
- `Auto` → Light grey

## Filters to Create

Set up these filters in Gmail (Settings → Filters and Blocked Addresses → Create a new filter):

### Filter 1: Skip Newsletters / Promotions
**Matches:** `from:(newsletter OR noreply OR no-reply OR unsubscribe) OR list:*`
**Action:**
- Skip Inbox
- Apply label: `TRIAGE/Processed`
- Never mark as important

### Filter 2: Skip Bounces / Auto-replies
**Matches:** `from:(mailer-daemon OR postmaster) OR subject:(auto-reply OR "out of office" OR "automatic reply" OR "delivery status" OR "undeliverable")`
**Action:**
- Skip Inbox
- Apply label: `TRIAGE/Processed`

### Filter 3: Skip Internal Staff
**Matches:** `from:(@yourdomain.com)` *(replace with your actual domain)*
**Action:**
- Do not apply TRIAGE labels (let these stay in normal inbox)
- Optionally: Apply label `Internal`

### Filter 4: Client Inbound (catch-all for everything else)
**Matches:** *(This is handled by the Apps Script ingestThreads function, not a Gmail filter)*
**Note:** The Apps Script queries `in:inbox -label:TRIAGE/Processed` to find new threads.

## How Filters and Labels Work Together

```
Incoming email
  │
  ├─ Newsletter/noreply? → Skip inbox, mark Processed
  ├─ Bounce/auto-reply?  → Skip inbox, mark Processed
  ├─ Internal staff?     → Leave in inbox (no triage)
  │
  └─ Client email → Stays in inbox
                      │
                      └─ Apps Script (every 15 min)
                           ├─ Adds to INBOX_TRACKER sheet
                           ├─ Labels: TRIAGE/Processed + TRIAGE/0-Inbox
                           ├─ Classifies → sets category + template
                           └─ Creates draft → labels TRIAGE/Auto
```

---

## Setup Steps

1. **Go to Gmail Settings** → Labels tab
2. **Create each label** listed above (type the full path like `TRIAGE/0-Inbox` — Gmail creates the nesting automatically)
3. **Go to Gmail Settings** → Filters tab
4. **Create Filter 1** (newsletters) with the criteria and actions above
5. **Create Filter 2** (bounces) with the criteria and actions above
6. **Create Filter 3** (internal) — update the domain to match your organisation
7. **Test:** Send a test email, verify it lands in inbox without any TRIAGE labels. Then run `ingestThreads` from the sheet menu and confirm the thread appears in the tracker.

---

## Important Notes

- The `TRIAGE/Processed` label is the key signal the system uses to avoid re-processing threads
- **Never manually remove** `TRIAGE/Processed` unless you want the thread re-ingested
- Staff should use labels `1-Needs Reply` through `4-Closed` to visually track status in Gmail (the system also updates these automatically via `syncSentStatus`)
- The system **never sends emails** — it only creates drafts and applies labels
